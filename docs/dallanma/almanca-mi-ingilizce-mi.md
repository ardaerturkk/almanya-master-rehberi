# Almanca Programa mı, İngilizce Programa mı?

::: info Bu sayfa ne için
Program dilini seçmek, sonraki her adımı (dil sınavı, başvuru havuzu, hayatın Almanya'da
sosyal boyutu) etkiliyor. Burada iki yolu karşılaştırıyoruz.
:::

## Karşılaştırma

| | **Almanca program** | **İngilizce program** |
| --- | --- | --- |
| Gerekli dil belgesi | Almanca (genelde B2/C1 — TestDaF 4x4 veya DSH-2) | İngilizce (genelde IELTS 6.0-7.0 veya TOEFL iBT 80-92, program bazlı değişir, bazı rekabetçi programlar 100+) |
| Program seçeneği sayısı | Daha fazla (Almanca, Almanya'daki eğitimin varsayılan dili) | Sınırlı ama artan sayıda, özellikle STEM ve işletme alanlarında yaygın |
| Günlük hayat/entegrasyon | Anmeldung, banka, doktor gibi resmi işlerde Almanca bilmek büyük avantaj | Üniversite içinde İngilizce yeterli olsa da günlük hayat için Almanca gerekebiliyor |
| İş piyasası (mezuniyet sonrası) | Almanca bilmek iş bulma şansını belirgin şekilde artırıyor | Bazı sektörlerde (tech, araştırma) İngilizce yeterli olabiliyor, ama çoğu işte Almanca aranıyor |
| Hazırlık süresi | Sıfırdan B2/C1'e genelde 1-2 yıl gerektirir | İngilizce zaten iyiysen ek hazırlığa gerek kalmayabilir |

## Hangi yol sana uygun?

- **Almancan zaten iyi veya öğrenmeye vaktin/isteğin varsa**: Almanca program hem daha fazla
  seçenek sunuyor hem de mezuniyet sonrası iş piyasasında avantaj sağlıyor.
- **Hızlı başvurmak istiyorsan ve İngilizcen güçlüyse**: İngilizce program, dil hazırlığı için
  yıllar kaybetmeden başvurmanı sağlıyor — ama Almanya'da yaşarken günlük Almanca ihtiyacını
  göz ardı etme.
- **Karma strateji**: İngilizce programa başvurup, program süresince paralel Almanca öğrenmek
  yaygın bir yol — mezuniyet sonrası iş arama sürecine ([Adım 32](/faz-7-sonrasi/32-mezuniyet-sonrasi))
  daha hazır girersin.

## Dil belgesi süreci

Detaylı dil sınavı bilgisi (hangi sınav, ücret) için [Adım 4: Dil Sınavları](/faz-1-hazirlik/04-dil)
sayfasına bak.

::: info Sınav ücretleri
TestDaF (Almanya'da 210-215 EUR, Türkiye'de İstanbul Üniversitesi-Cerrahpaşa merkezinde 155 EUR), IELTS (IDP Türkiye 12.210 TL), TOEFL iBT (Türkiye 185 USD) ücretleri [Adım 4](/faz-1-hazirlik/04-dil) sayfasında kaynaklarıyla listeli. Goethe ve telc Türkiye ücretleri resmi sayfalardan alınamadı, kayıt ekranından teyit et.
:::
